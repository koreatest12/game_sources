# 초파리 무한 DOOM ∞ — Astra Prototype Source

ChatGPT/Astra에서 만든 브라우저 기반 독립 미니게임 프로토타입을 GitHub에서 직접 실행·수정할 수 있도록 분리한 소스입니다.

## 주요 기능

- 무한 웨이브와 난이도 상승
- 초파리형 적 / 엘리트 적
- 아이템 자동 습득 및 공격력·체력·속도·발사속도 성장
- 8 입력 → 12 은닉 → 4 출력의 소형 신경망
- Q-Learning과 신경망 점수를 혼합한 자동 플레이
- 명중·처치·아이템 획득 보상 / 피격·벽 충돌 감점
- LocalStorage를 이용한 AI 학습값 유지
- 직접 조작 및 1× / 2× / 4× 진행 속도
- 외부 라이브러리 없는 HTML/CSS/JavaScript 단독 실행

## 실행

```bash
cd astra-fly-doom
python -m http.server 8000
```

브라우저에서 `http://localhost:8000` 접속.

정적 파일이므로 `index.html`을 직접 열어도 대부분 동작하지만, 로컬 HTTP 서버 실행을 권장합니다.

## 조작

- `WASD`: 이동
- `← / →`: 회전
- `SPACE`: 발사
- `P`: 일시정지
- UI의 `자동 플레이 / 직접 조작` 버튼으로 AI 제어 전환

## AI 구현 범위

이 게임의 신경망은 실제 초파리 뇌를 재현한 생물학적 모델이 아닙니다. 게임 AI의 행동 선택을 설명하기 위한 경량 인공 신경망입니다.

행동 선택 점수는 다음 두 값을 조합합니다.

- 신경망 출력: 60%
- Q-Learning 값: 40%

학습 데이터는 브라우저의 `localStorage`에 저장되며 ChatGPT/Astra 모델 자체를 재학습시키지는 않습니다.

## 라이선스/주의

이 프로젝트는 DOOM에서 영감을 받은 독립 프로토타입이며 DOOM 원본 엔진, 코드, 그래픽, 오디오 자산을 포함하지 않습니다.
